# 🚗 Cars Rental App

**Cars Rental App** — это мобильное приложение для комплексной автоматизации бизнеса по сдаче автомобилей в аренду. Проект позволяет вести учет автопарка, управлять базой арендаторов, отслеживать статусы аренд и полностью автоматизировать финансовые потоки.

## ✨ Ключевые возможности

### 🌍 Локализация и персонализация
* **Онбординг:** При первом запуске пользователь настраивает язык интерфейса и основную валюту.
* **Главный экран (Dashboard):** Интеллектуальная панель, отображающая сущности, с которыми велась недавняя работа, для быстрого доступа.

### 📱 Удобная навигация и UI
* Интуитивно понятная нижняя панель навигации (Bottom Navigation Bar) с 5 основными разделами: **Дом, Машины, Водители, Аренды, Финансы**.
* Грамотная обработка пустых состояний (Empty States): заглушки с призывами к действию при отсутствии записей.

### 🏢 Управление бизнесом
* **Создание записей:** Полноценные экраны добавления новых машин, водителей и финансовых операций с поддержкой загрузки фотографий.
* **Логика аренды:** Связывание водителя и автомобиля, настройка периодичности оплат (понедельно, помесячно, вручную) и контроль сроков сдачи.

### 🤖 Автоматизация финансов (Smart Parsing)
* Встроенный модуль автоматического парсинга банковских выписок (Сбербанк) из PDF-формата напрямую в базу данных, минуя создание промежуточных Excel-файлов.

---

## 🛠 Технологический стек

* **Язык:** Python 3.12
* **UI Framework:** [Flet](https://flet.dev/) (построение кроссплатформенных интерфейсов)
* **База данных:** SQLite
* **ORM:** SQLAlchemy 2.0
* **Парсинг:** pdfminer.six (извлечение текста из PDF)

## 🚀 Установка и запуск (для разработчиков)

Проект легко разворачивается в локальной среде (в том числе на WSL).

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/alisher2011ali-netizen/Cars-Rental-App.git
   cd Сars-Rental-App
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для Linux / WSL:
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение:**
   ```bash
   # Обычный запуск:
   python -m app.main
   # Запуск в режиме Hot Reload (автообновление при изменении кода):
   flet run -d app/main.py
   ```

## 📦 Сборка APK для Android

Для сборки установочного файла `.apk` требуются установленные Flutter SDK и Android Command Line Tools.

```bash
flet build apk app/main.py --include-packages app
```
*Готовый файл появится в папке `build/apk/`.*

## 🤝 Благодарности и Open Source

Модуль парсинга банковских выписок (`app/parsing/`) основан на открытом проекте [Sberbank2Excel](https://github.com/Ev2geny/Sberbank2Excel) от Ev2geny. Огромное спасибо разработчикам этого проекта!

Оригинальный код был подвергнут глубокому реверс-инжинирингу: извлечено ядро бизнес-логики, полностью удалены элементы графического интерфейса и тяжеловесные зависимости (`pandas`, `XlsxWriter`). Написан фасад-адаптер для прямого преобразования данных из PDF в словари Python, что позволило оптимизировать производительность и адаптировать код для бесшовной сборки в мобильное приложение.
